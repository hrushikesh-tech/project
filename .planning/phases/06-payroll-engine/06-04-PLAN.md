## Threat Model

<threat_model>

- **T-06-13: Unverified happy-path bias** - Without integration coverage, payroll can appear correct in unit tests while API wiring, worker orchestration, or persistence contracts are broken.
- **T-06-14: Unproven compensation safety** - Failure reversal logic must be tested with integration-style state transitions, not only mocked method calls.
- **T-06-15: Performance wishful thinking** - PAY-06 requires an explicit benchmark path; otherwise the 10,000-employee target is unverified.
- **T-06-16: Validation drift** - If `06-VALIDATION.md` is not updated with real commands and artifacts, execution-time sign-off becomes ambiguous and easy to bypass.
  </threat_model>

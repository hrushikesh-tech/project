## Threat Model

<threat_model>

- **T-08-10: Cross-runtime blind spot** - Without both Python and Node verification, one side of the forecasting system can be green while the end-to-end behavior is broken.
- **T-08-11: Quality-gate regression** - If tests do not explicitly check the 20% MAPE rule, later refactors can silently weaken the main product guarantee.
- **T-08-12: Validation drift** - Without a concrete `08-VALIDATION.md`, phase sign-off becomes ambiguous and easy to overstate.

</threat_model>

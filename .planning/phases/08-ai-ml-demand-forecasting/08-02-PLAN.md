# Plan 08-02: FastAPI Forecasting Runtime, Training Pipelines, and Prediction API

<objective>
Turn the current FastAPI stub into a real ML runtime: add forecasting dependencies, implement the preprocessing and training pipelines for Prophet and LSTM, expose the required forecasting endpoints, and enforce the MAPE gate at prediction time.
</objective>

<must_haves>

- The ML service can train Prophet with IQR outlier removal and multiplicative seasonality
- LSTM training only runs for SKUs with at least 500 points and uses early stopping
- `POST /ml/predict` returns confidence intervals and rejects low-quality models
- The service exposes the roadmap-required train, predict, model-list, model-detail, retrain-all, and health endpoints
- The runtime stores and loads versioned model artifacts through an explicit registry layer

</must_haves>

<action>
Implement the core forecasting pipeline with the exact behavior below:

1. Preprocessing layer:
   - accept daily product-level demand series
   - remove outliers using IQR
   - preserve enough metadata to report point counts and training windows
2. Prophet path:
   - train for every eligible SKU
   - use multiplicative seasonality
   - calculate MAPE from held-out or validation predictions
3. LSTM path:
   - run only when the series has at least 500 points
   - use a 60-day lookback
   - implement early stopping
   - calculate MAPE on a held-out validation segment
4. Registry layer:
   - persist or load versioned artifacts via an explicit registry service
   - return artifact metadata needed for promotion and later prediction calls

Do not implement the LSTM path as best-effort without the 500-point gate; the locked requirement makes that gate mandatory.
</action>

## Threat Model

<threat_model>

- **T-08-04: Prediction without enforcement** - If the 20% MAPE rule is only metadata and not request-path behavior, the service can silently serve unqualified forecasts.
- **T-08-05: LSTM misuse on sparse SKUs** - Running LSTM without the 500-point gate will create noisy models and erode trust in the quality gate.
- **T-08-06: Stub-shaped API surface** - If the endpoint contract is incomplete, NestJS orchestration and later BI consumers will not have a stable service surface to build on.

</threat_model>

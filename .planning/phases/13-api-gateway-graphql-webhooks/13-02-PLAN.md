| Boundary | Description |
|----------|-------------|
| external clients -> auth and BI APIs | Authentication and analytics reads cross from untrusted requests into protected controller paths |
| tenant users/admins -> notification and webhook config APIs | Role-gated notification configuration and webhook endpoint management cross a tenant boundary |
| controller docs -> internal integrators | Misdocumented contract details can break internal integrations even if handlers still work |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-13-05 | Elevation of Privilege | notification webhook admin APIs | mitigate | Preserve tenant-admin role gates and add integration coverage for forbidden access under the shared error contract |
| T-13-06 | Tampering | module-specific exception filters | mitigate | Normalize BI and notification error paths so module-local filters cannot silently bypass the shared envelope |
</threat_model>

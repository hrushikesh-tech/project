<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted HTTP requests -> Nest bootstrap | Rate limiting and security headers must take effect before business logic runs |
| upload body -> AP/AR ingress | User-supplied files cross into storage and OCR workflows here |
| controller params/headers -> tenant-scoped services | Malformed IDs or tenant overrides must be rejected before they shape database queries |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-03 | Denial of Service | auth/OCR/payroll entry points | mitigate | Apply exact per-route throttling thresholds with identity-aware keys and clear `429` responses |
| T-14-04 | Tampering | file uploads | mitigate | Reuse strict size plus magic-byte/MIME allowlist validation before OCR/storage work starts |
| T-14-05 | Information Disclosure | browser/API headers | mitigate | Centralize HSTS, frame denial, and report-first CSP from one bootstrap path |
</threat_model>

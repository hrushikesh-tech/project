<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> NextAuth/session helpers | Auth cookies and refresh behavior cross from the browser into the frontend auth runtime |
| Next.js response -> user agent | Security headers and CSP policy affect every rendered web response |
| login form input -> credentials exchange | Invalid or malformed auth input must be stopped before it reaches the backend |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-04 | Information Disclosure | browser responses | mitigate | Add centralized frame denial, no-sniff, HSTS, and report-first CSP headers through Next.js |
| T-14-06 | Spoofing | web auth secret handling | mitigate | Remove committed fallback secrets and require environment-provided auth secret material |
| T-14-07 | Tampering | login/auth form inputs | mitigate | Move login onto the same Zod-backed validation pattern used by the existing operational forms |
</threat_model>

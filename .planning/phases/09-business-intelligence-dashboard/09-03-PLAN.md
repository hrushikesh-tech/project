# Plan 09-03: Fixed Metric Aggregation Services and SSE Refresh Contract

<objective>
Implement the cross-domain BI aggregation layer for the eight fixed metrics and expose the lightweight SSE refresh contract that streams dashboard invalidation events every 30 seconds.
</objective>

<must_haves>

- All eight roadmap metrics have deterministic backend aggregation services
- Metric calculations honor the locked domain rules from finance, HR, supply-chain, forecasting, and projects
- `project_budget_vs_actual` returns a safe empty response when no project data exists yet
- The SSE endpoint emits lightweight refresh events, not full metric datasets
- Unit coverage proves the fixed metric semantics and key edge cases

</must_haves>

## Threat Model

<threat_model>

- **T-09-07: Metric semantic drift** - If BI does not reuse domain source-of-truth rules, dashboard numbers will contradict the ERP modules they summarize.
- **T-09-08: Premature forecast comparison** - If future-dated predictions are included in accuracy math, the metric will misrepresent model quality.
- **T-09-09: Overbuilt stream channel** - If SSE carries full datasets, refresh cost and complexity will balloon before the frontend builder exists.

</threat_model>

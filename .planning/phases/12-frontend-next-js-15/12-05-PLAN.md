<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| BI widget configuration -> dashboard state | User layout edits affect saved dashboard configuration |
| stream events -> query cache | Live refresh signals trigger data updates in the UI |
| project task data -> Gantt interactions | Scheduling data becomes draggable timeline state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-13 | Tampering | BI widget configuration | mitigate | Constrain widget config to approved typed contracts and forbid free-form metric/query semantics |
| T-12-14 | Denial of Service | Gantt rendering path | mitigate | Isolate layout calculations, add realistic-scale smoke coverage, and optimize for the 500-task requirement from the start |
| T-12-15 | Elevation of Privilege | project scheduling interactions | mitigate | Keep edits bounded to allowed scheduling changes and honor backend project-management constraints rather than inventing client-side rule overrides |
</threat_model>

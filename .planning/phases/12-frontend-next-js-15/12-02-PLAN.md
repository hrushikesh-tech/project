<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> auth endpoints | Credentials and session transitions cross from untrusted client input into auth flows |
| session -> protected routes | Authorization state governs whether dashboard UI may render |
| shell navigation -> module routes | Role-home and module navigation decisions gate access to ERP surfaces |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-04 | Spoofing | Auth.js and backend auth bridge | mitigate | Bind login, refresh, logout, and `me` reads to the existing backend contract instead of inventing a second auth protocol |
| T-12-05 | Elevation of Privilege | `apps/web/src/middleware.ts` | mitigate | Enforce protected-route redirects before rendering `(dashboard)` routes and derive role-home from session claims |
| T-12-06 | Information Disclosure | app shell rendering | mitigate | Delay protected-shell rendering until tenant and role identity are resolved and verified |
</threat_model>

## Trust Boundaries

| Boundary                                          | Description                                                                                     |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| release helper -> GitOps values files             | Bad tag rewrites could promote the wrong artifact or corrupt the environment overlays           |
| checked-in exception files -> security truth      | Hidden or vague ignore policy could normalize unreviewed HIGH/CRITICAL risk                     |
| root verification scripts -> future workflow YAML | If root scripts are not truthful, CI and deploy workflows will encode stale command assumptions |

## STRIDE Threat Register

| Threat ID | Category    | Component                 | Disposition | Mitigation Plan                                                                   |
| --------- | ----------- | ------------------------- | ----------- | --------------------------------------------------------------------------------- |
| T-17-01   | Tampering   | values overlays           | mitigate    | Add deterministic tag fields and one checked-in update helper with dry-run mode   |
| T-17-02   | Repudiation | vulnerability exceptions  | mitigate    | Keep Snyk and Trivy exceptions in checked-in files with reviewable structure      |
| T-17-03   | Tampering   | workflow command contract | mitigate    | Add truthful root verification scripts before workflow YAML starts consuming them |

</threat_model>
